# Superseded Cross-Repository Terminology

The previous table assigned one shared runtime meaning to terms used by
different repositories. That transfer is withdrawn.

Terms must now be read inside the code, version and claim boundary of the
specific object that uses them:

1. [start-here](https://github.com/LalaSkye/start-here)
2. [commit-gate-core](https://github.com/LalaSkye/commit-gate-core)
3. [obligation-bound-policy-admission-lab](https://github.com/LalaSkye/obligation-bound-policy-admission-lab)

Shared vocabulary does not establish shared implementation, proof inheritance,
priority or copying.
